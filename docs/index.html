Beim Scannen wird das Produktionsdatum im Barcode um 30 Tage erhöht. Alle anderen Datenfelder bleiben erhalten; die Luhn-Prüfziffer wird neu berechnet. Zweistellige Jahreszahlen werden als 2000–2099 gelesen. Bei manueller Eingabe werden vom Ablaufdatum wie bisher 181 Tage abgezogen. Kamerabilder werden nur auf deinem Gerät verarbeitet.
